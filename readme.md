Программа-резидент, постоянно ищущая выпадающий список (combobox) с рабочими наборами (worksets) в строке состояния Autodesk Revit (через колбеки в EnumWindows/EnumChildWindows).
В  случае выбора в данном комбобоксе не своего рабочего набора, программа worksets_ctrl выдаёт окно "Выберите свой рабочий набор":
